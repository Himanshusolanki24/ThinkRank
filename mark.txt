1. PROJECT OVERVIEW & PROBLEM STATEMENT
================================================================================

PROJECT NAME: ThinkRank
TAGLINE: "Map Your Skills. Chart Your Path. Rank Higher."

WHAT IS THINKRANK?
ThinkRank is an AI-powered platform that creates a living genome map of your skills,
provides personalized learning roadmaps, and accelerates your career growth. It 
analyzes your resume, GitHub, and coding profiles (LeetCode, CodeChef, etc.) to
generate a comprehensive, interactive visualization of your technical capabilities.

THE PROBLEM WE SOLVE:
 • Developers struggle to accurately assess their current skill levels and gaps.
 • Learning paths are often generic and not tailored to an individual's unique strengths.
 • Tracking progress across multiple platforms (GitHub, LeetCode) is fragmented.
 • Interview preparation lacks personalization and company-specific focus based on
   the candidate's actual skill profile.
 • Certificates are treated as static PDFs instead of dynamic career boosters.

WHO IS IT FOR?
 • Software developers looking to upskill and track their career growth
 • Job seekers preparing for MNC interviews
 • Students wanting structured learning roadmaps
 • Tech leads and recruiters evaluating skill profiles

6. CORE CONCEPTS (Skill Genome, Coding Signals, CertGenome)
================================================================================

THE SKILL GENOME:
Think of the Skill Genome as an RPG character stat sheet, but for real-world
software engineering. Instead of just saying "I know Python," the genome maps:
 • Core Language (Python)
 • Frameworks (FastAPI, Django)
 • Concepts (AsyncIO, ORMs)
 • Proficiency Level (0-100)
This creates a living, interconnected web of skills.

CODING SIGNALS:
A dedicated Python microservice that acts as an aggregator. It takes a user's
handles for LeetCode, CodeChef, HackerRank, etc., and uses Playwright to scrape
their real-time stats, submission history, and ratings. This data is normalized
into a single activity heatmap.

CERTGENOME:
The AI layer mapping certificates to career placement. It validates uploaded
credentials, extracts metadata via OCR/LLMs, scores their industry credibility,
and mathematically propagates skill proficiency points to the user's Skill Genome.

7. COMPLETE DATA FLOW (Step-by-Step)
================================================================================

SCENARIO: User uploads an AWS Certificate to improve their Cloud Engineer readiness.

STEP 1: UPLOAD & QUEUE
 → User uploads PDF in Frontend.
 → Backend stores PDF in Supabase Storage.
 → Job enqueued in Redis (BullMQ).

STEP 2: OCR & EXTRACTION
 → Python microservice (cert_ai) picks up job.
 → PDF converted to text via OCR.
 → LLM extracts: Issuer, Dates, Topic, Name.

STEP 3: VALIDATION & SCORING
 → Certificate validated against known issuer patterns.
 → Fraud heuristics applied.
 → AI Credibility Engine assigns a score (e.g., 92/100).

STEP 4: GRAPH UPDATE
 → Backend recalculates Skill Genome.
 → AWS nodes get boosted; confidence score increases.
 → Placement ROI Engine recalculates overall readiness score.

STEP 5: NEXT ACTIONS
 → User UI updates in real-time via WebSockets.
 → AI Next Action Engine suggests next logical cert (e.g., AWS SAA) or a 
   specific micro-project to cement knowledge.

11. CERTGENOME: AI CERTIFICATE INTELLIGENCE (NEW MODULE)
================================================================================

VISION:
Deep integration with Skill Genome to evaluate, recommend, and validate 
certifications, computing exact ROI for career placement and skill graph progression.
This is not a generic course catalog; it's an intelligent validation engine.

MODULES OVERVIEW:

1. AI CERTIFICATE RECOMMENDATION ENGINE
   - Evaluates: target companies, skill gaps, budget, placement goals, coding performance.
   - Output: Highly ranked, industry-recognized certificates (AWS, Meta, Google, Kubernetes).
   - Algorithm: Collaborative filtering mixed with Vector Similarity (mapping user 
     skill-gap embeddings to certificate outcome embeddings).

2. CERTIFICATE CREDIBILITY ENGINE
   - Generates: Credibility Score (0-100), Placement Impact Score, Recruiter Trust Index.
   - Differentiates strong certifications from low-value random ones using an AI-weighted
     scoring heuristic based on market demand and assessment rigor.

3. AI CERTIFICATE VALIDATION ENGINE
   - Input: PDFs, URLs, badge links, screenshots.
   - Processing: OCR pipeline (Tesseract/Textract) -> AI Parsing -> Verification API.
   - Fraud Detection: Heuristics to detect duplicate hashes, manipulated dates, or fake issuers.

4. SKILL GENOME & PLACEMENT GENOME INTEGRATION
   - Dynamic Skill Graphs: Completing an AWS cert propagates weighted confidence 
     scores through the graph (e.g., +20% Cloud Engineering, +10% Backend).
   - Placement Readiness: Recalculates ATS compatibility and company readiness.

5. AI CAREER ROI ENGINE & SMART LEARNING PATHWAYS
   - Predictive AI estimates salary impact, role eligibility, and recruiter visibility.
   - Generates DAG-based certification ladders (e.g., AWS CCP → AWS SAA → Kubernetes).

6. AI NEXT ACTION ENGINE
   - Continuous career loops: recommends next project, GitHub contributions, or LeetCode 
     topics based on newly acquired certificate knowledge.

7. FRONTEND EXPERIENCE
   - Futuristic UI, recruiter-grade dashboards, graph visualizations, animated 
     intelligence panels (Framer Motion, D3.js).

12. CERTGENOME DATABASE & SYSTEM DESIGN
================================================================================

DATABASE SCHEMA (PostgreSQL / Supabase):
- Users: user_id, placement_score, current_role, target_role
- Certificates: cert_id, issuer, name, difficulty_level, credibility_score, vector_embedding
- User_Certificates: id, user_id, cert_id, status, verified, verification_url, extracted_data (JSONB)
- Skill_Nodes: node_id, skill_name, category
- Cert_Skill_Edges: cert_id, skill_id, weight (impact factor)
- Verification_Logs: log_id, user_cert_id, ocr_hash, fraud_flag (boolean)

EVENT-DRIVEN ARCHITECTURE & ASYNC JOBS:
1. Certificate Upload -> S3/Supabase Storage -> Trigger Webhook.
2. Webhook -> Redis Queue (BullMQ/Celery) -> Worker picks up file.
3. Worker -> OCR Pipeline -> LLM Extraction -> Fraud Check -> DB Update.
4. DB Update Trigger -> Async Recalculation of Skill Genome -> Broadcast UI update via WebSockets.

13. CERTGENOME AI & API ARCHITECTURE
================================================================================

AI SYSTEM DESIGN:
- Embedding Pipeline: Use OpenAI `text-embedding-3-small` or SentenceTransformers to embed
  certificate descriptions and user skill gaps.
- RAG Architecture: Vector search in pgvector to find certificates that maximally 
  cover the user's missing "target_role" skills.
- Certificate Similarity Engine: Cosine similarity on pgvector to recommend alternatives.
- LLM Orchestration: LangChain pipelines to sequence OCR extraction -> JSON parsing -> Validation.
- Guardrails: Strict Pydantic schemas for LLM output validation; fallback to human review 
  if fraud_score > 0.8.

API ARCHITECTURE (FastAPI Microservice):
- POST /api/v1/certificates/upload
  Handles multipart/form-data. Uploads to Supabase Storage, enqueues validation job.
- GET /api/v1/certificates/recommendations?target_role={role}&budget={max}
  Executes pgvector similarity search against user skill graph.
- GET /api/v1/certificates/{id}/roi
  Calculates predictive Placement Impact using heuristical models.
- POST /api/v1/webhooks/validation-complete
  Updates Postgres and triggers Socket.io event to frontend.
